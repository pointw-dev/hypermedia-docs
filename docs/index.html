What is hypermedia?
Quickstart
⛓️‍💥

Fight coupling, not tight coupling

If your clients break when the server changes, you’re stuck in a tightly coupled system. Hypermedia decouples client and server interactions, letting each evolve independently without breaking the other.

😊

APIs that are a joy to use

Hypermedia APIs offer an intuitive, flexible and enjoyable experience, making your API not just a powerful tool, but a delight to use.

📆

Timeless API design

Craft your API for the long haul. Distributed services that last decades will change over time. With hypermedia you can make these changes safely, without breaking your clients.
